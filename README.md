An Android app built with Jetpack Compose.

## Features

- Built with modern Android architecture and Jetpack Compose.
- Sideloadable via APK.
- Discoverable on [KomiStore](https://komistore.app).

## Installation

You can download the latest APK from the [GitHub Releases](../../releases/latest).

1. Download the `Freedium-vX.Y.Z.apk` file.
2. Open the downloaded file on your Android device.
3. If prompted, allow installation from unknown sources.
4. Install and enjoy!

## Build Instructions

To build the project locally, you will need Android Studio and JDK 17.

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/freedium.git
   ```
2. Open the project in Android Studio.
3. Build the project using the **Build -> Make Project** menu, or via the command line:
   ```bash
   ./gradlew assembleDebug
   ```
